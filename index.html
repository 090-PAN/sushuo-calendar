📅 广外南活动日历

一次订阅，活动自动同步进你的手机日历，到点弹提醒，新活动自动出现——不用每次来问 bot，也不用重复设置。

一键订阅（自动同步） 下载 .ics 导入

订阅 = 日历 App 每隔几小时自动回源拉取，活动有更新就自动改好；下载 = 一次性导入，之后要手动重导。

怎么订阅？

  • iPhone：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历，粘贴上面的订阅地址（webcal 开头）。
  • 安卓：系统日历 → 设置 → 添加日历 → 通过链接订阅（不同品牌入口略有差异）。
  • 电脑：Outlook / Google 日历 →「通过 URL 添加日历」粘贴订阅地址。
  • 不会弄？点「下载 .ics」先手动导入也行，等熟悉了再换订阅。

怎么停止推送 / 退订？

  • 在手机「设置 → 日历 → 账户 → 已订阅的日历」里删除「广外南活动日程」即可，随时可退订，不留任何记录。
  • 如果是邮件周报：把你的邮箱从推送名单里删掉，或回复「退订」。
